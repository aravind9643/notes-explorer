# Tasks and reminders

Any line like `- [ ] Send the report @due(2026-11-01)` becomes a task in the **Tasks** view, with a reminder on the due date.

- Add `@every(week)` and the next one is created when you tick it.
- Filter by overdue, due this week or `#tag`.
- Right-click a note and choose **Show as Board** to drag tasks between its `##` sections.
